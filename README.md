# HANDOFF 退去立会依頼 PWA V0.5
## 端末保存マスター完成版

### 方針
- GitHub Pagesにはアプリ本体だけを置きます。
- 物件マスター・立会業者マスターは各端末のブラウザ内（localStorage）に保存します。
- 入居者名、電話番号、退去情報などの業務データをGitHubの共通JSONへ保存する仕様ではありません。

### マスター管理
- 物件：物件名、住所
- 立会業者：会社名、担当者名、メールアドレス、電話番号
- 登録、編集、削除に対応
- JSONバックアップ保存／復元に対応

### 別端末へマスターを移す
1. 元端末で「⚙ マスター管理」→「バックアップ保存」
2. 保存された `HANDOFF_マスター_YYYY-MM-DD.json` を別端末へ送る
3. 別端末で「⚙ マスター管理」→「バックアップ読込」

### GitHub更新
既存HANDOFFリポジトリのアプリファイルをこのV0.5で上書きしてください。
V0.4で作成した `data/masters.json` は使用しません。空であれば削除して構いません。
