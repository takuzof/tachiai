# HANDOFF 退去立会依頼 PWA V0.6
## Excel / CSV 物件マスター読込版

V0.5の端末保存方式を維持し、物件マスターをExcel/CSVから端末内へ一括登録できるようにしました。

### 対応ファイル
- Excel: `.xlsx`, `.xls`
- CSV: `.csv`

### 対応する列名
物件名列は、以下のいずれかを自動認識します。
- 物件名
- 建物名
- 物件名称
- 建物名称
- マンション名
- アパート名
- 名称
- name

住所列は任意で、以下を自動認識します。
- 住所
- 所在地
- 物件住所
- 建物住所
- address

### 読込方法
1. HANDOFF → ⚙ マスター管理
2. 物件マスター
3. 「Excel / CSVを選択」
4. ファイルを選択
5. 読込結果を確認
6. 「既存マスターへ追加」または「全置換」を選択
7. 「この内容を物件マスターへ登録」

### プライバシー
選択したExcel/CSVはブラウザ内で処理します。
物件データをGitHubやこのチャットへ送信する処理はありません。
Excel解析用ライブラリ自体はCDNから読み込みますが、選択したファイル内容を外部送信する処理はありません。
