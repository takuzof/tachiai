# 退去立会依頼 PWA V0.1

## できること
- iPhone/PCブラウザで利用
- 解約通知書を撮影・画像選択
- Tesseract.jsによる日本語OCR
- 物件名、号室、借主名、入居者名、電話番号、立会者、立会希望日、退去予定日、解約予定日の自動抽出
- 読取結果の手修正
- 添付用の写真・PDFを複数追加
- 業者マスター（端末内保存）
- メール件名・本文の自動生成
- 添付資料を1つのPDFに結合
- iPhoneのWeb Share APIで共有シートを開く
- 共有先で「メール」を選択して送信

## 注意
- OCRライブラリとPDFライブラリをCDNから読み込むため、初回利用時はインターネット接続が必要です。
- iPhone Safariの共有シートで「メール」を選んだ際、本文の引き継ぎ方はiOS側の仕様に依存します。
  本文が入らない場合に備えて「本文をコピー」ボタンもあります。
- Safariから直接 file:// で開くとPWA/Service Workerが動作しません。Webサーバー上に配置してください。
- 業者情報は localStorage に保存されます。
- OCR結果は端末内で処理されますが、Tesseractのモデル取得時は外部CDNへアクセスします。

## Windowsで試す最短手順
1. ZIPを展開
2. フォルダ内で簡易Webサーバーを起動
   - Pythonがある場合: `python -m http.server 8080`
3. Chrome/Edgeで `http://localhost:8080` を開く

## iPhoneで使う場合
同じフォルダをHTTPSで公開し、Safariでアクセスしてください。
ホーム画面に追加するとPWAとして使えます。
